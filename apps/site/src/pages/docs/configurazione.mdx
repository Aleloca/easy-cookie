La configurazione è un oggetto JSON semplice. Il server dei consensi la salva, la versiona e la consegna ai siti, quindi deve sopravvivere a `JSON.stringify` senza perdere nulla: niente funzioni, niente `RegExp` (le espressioni regolari dei cookie si scrivono come stringhe con `pattern: true`).

In TypeScript, `defineConfig()` non fa nulla a runtime ma ti dà il controllo dei tipi:

```ts
import { defineConfig } from '@easy-cookie/core/shared';

export default defineConfig({
  revision: '2026-11-13',
  categories: { necessary: { readOnly: true }, measurement: {} },
});
```

`validateConfig(config)` restituisce l'elenco dei problemi trovati (vuoto se è valida). Il runtime la esegue all'avvio e scrive gli avvisi in console; il server la esegue prima di pubblicare una revisione e rifiuta le configurazioni non valide.

Un tipo ricorrente è `Localized`: una stringa, oppure una mappa lingua → stringa, per esempio `{ it: '2 anni', en: '2 years' }`.

## Campi principali

| Campo | Tipo | Predefinito | Note |
|---|---|---|---|
| `revision` | `string` | **obbligatorio** | Revisione della policy. Se cambia, tutti i visitatori rivedono il banner. Una data va benissimo: `'2026-11-13'`. |
| `expiryDays` | `number` | `182` | Giorni dopo i quali la scelta scade e il banner torna. Tra 1 e 395. |
| `categories` | `Record<string, CategoryDeclaration>` | **obbligatorio** | Almeno una categoria, e almeno una con `readOnly: true`. |
| `services` | `Record<string, ServiceDeclaration>` | `{}` | Servizi di terze parti e i loro cookie. |
| `policyUrl` | `Localized` | nessuno | Link alla cookie policy nel primo livello del banner. |
| `language` | oggetto | `{ default: 'it' }` | Vedi [language](#language). |
| `cookie` | oggetto | vedi sotto | Il cookie tecnico che ricorda la scelta. |
| `googleConsentMode` | oggetto | disattivato | Vedi [googleConsentMode](#googleconsentmode). |
| `log` | oggetto | nessuno | Server dei consensi. Senza, nessun record viene inviato. |
| `ui` | oggetto | vedi sotto | Posizione, pulsante di riapertura, schema colori. |
| `texts` | `Record<lang, DeepPartial<Texts>>` | testi IT/EN inclusi | Sovrascrive qualsiasi testo, per lingua. |
| `respectGpc` | `boolean` | `true` | Il segnale Global Privacy Control vale come rifiuto. |
| `hideFromBots` | `boolean` | `true` | Non mostra il banner a crawler e browser automatizzati. |

## categories

Gli id delle categorie sono stringhe libere (lettere, cifre, `_` e `-`). Cinque id hanno già titolo, descrizione, colore e segnali di Consent Mode, e corrispondono alle finalità 1–5 di Iubenda:

| Id | Finalità Iubenda | Segnali Consent Mode predefiniti |
|---|---|---|
| `necessary` | 1 · Necessari | `security_storage` |
| `functionality` | 2 · Funzionalità | `functionality_storage` |
| `experience` | 3 · Esperienza | `personalization_storage` |
| `measurement` | 4 · Misurazione | `analytics_storage` |
| `marketing` | 5 · Marketing | `ad_storage`, `ad_user_data`, `ad_personalization` |

Ogni categoria è un `CategoryDeclaration`:

| Campo | Tipo | Predefinito | Note |
|---|---|---|---|
| `readOnly` | `boolean` | `false` | Sempre attiva, non disattivabile. Da usare solo per i cookie tecnici. |
| `title` | `Localized` | dall'id noto, altrimenti l'id | Titolo nel pannello preferenze. |
| `description` | `Localized` | dall'id noto, altrimenti vuota | Spiegazione per il visitatore. |
| `gcm` | `GcmSignal[]` | dall'id noto, altrimenti `[]` | Segnali concessi quando la categoria è accettata. |
| `color` | `string` | dall'id noto | Colore del modulo nel mosaico del banner. Qualsiasi colore CSS. |

```ts
categories: {
  necessary: { readOnly: true },
  measurement: {},
  newsletter: {
    title: { it: 'Newsletter', en: 'Newsletter' },
    description: { it: 'Misura le aperture delle email.', en: 'Measures email opens.' },
    gcm: ['analytics_storage'],
    color: '#0f7f86',
  },
},
```

I valori ammessi per `GcmSignal` sono `ad_storage`, `ad_user_data`, `ad_personalization`, `analytics_storage`, `functionality_storage`, `personalization_storage`, `security_storage`.

## services

Un servizio collega un fornitore a una categoria e ne dichiara i cookie. Da qui nascono le tabelle del pannello preferenze, la cancellazione dei cookie alla revoca e la [cookie policy generata](/docs/cookie-policy/).

| Campo | Tipo | Predefinito | Note |
|---|---|---|---|
| `category` | `string` | **obbligatorio** | Id di una categoria dichiarata. |
| `label` | `Localized` | l'id del servizio | Nome mostrato al visitatore. |
| `provider` | `string` | nessuno | Ragione sociale del fornitore. |
| `purpose` | `Localized` | nessuno | A cosa serve, in una riga. |
| `privacyUrl` | `string` | nessuno | Informativa del fornitore. |
| `cookies` | `CookieDeclaration[]` | `[]` | Cookie impostati dal servizio. |

Ogni `CookieDeclaration`:

| Campo | Tipo | Predefinito | Note |
|---|---|---|---|
| `name` | `string` | **obbligatorio** | Nome esatto, oppure sorgente di un'espressione regolare se `pattern` è `true`. |
| `pattern` | `boolean` | `false` | Tratta `name` come espressione regolare, per esempio `'^_ga'`. |
| `duration` | `Localized` | nessuno | Durata leggibile: `{ it: '2 anni', en: '2 years' }`. |
| `description` | `Localized` | nessuno | A cosa serve il singolo cookie. |
| `domain` | `string` | il dominio del sito | Dominio del cookie, quando è di terza parte (`.youtube.com`). |

```ts
services: {
  ga4: {
    category: 'measurement',
    label: 'Google Analytics 4',
    provider: 'Google Ireland Ltd',
    purpose: { it: 'Statistiche sulle visite', en: 'Visit statistics' },
    privacyUrl: 'https://policies.google.com/privacy',
    cookies: [{ name: '^_ga', pattern: true, duration: { it: '2 anni', en: '2 years' } }],
  },
},
```

## cookie

Il cookie tecnico in cui il browser ricorda la scelta. È di prima parte e non contiene dati personali oltre a un id casuale.

| Campo | Tipo | Predefinito | Note |
|---|---|---|---|
| `cookie.name` | `string` | `'ec_consent'` | Cambialo solo se due istanze convivono sullo stesso dominio. |
| `cookie.domain` | `string` | il dominio corrente | Per esempio `.example.com` per condividere la scelta tra sottodomini. |
| `cookie.path` | `string` | `'/'` | |
| `cookie.sameSite` | `'Lax' \| 'Strict' \| 'None'` | `'Lax'` | `None` richiede `secure: true`. |
| `cookie.secure` | `boolean` | `true` | Applicato solo su HTTPS. |

## language

| Campo | Tipo | Predefinito | Note |
|---|---|---|---|
| `language.default` | `string` | `'it'` | Lingua di riserva per i testi. |
| `language.available` | `string[]` | `[default]` | Lingue offerte. Italiano e inglese hanno già tutti i testi. |
| `language.autoDetect` | `'document' \| 'browser' \| false` | `'document'` | `document` legge `<html lang>`, `browser` legge `navigator.language`. |

## googleConsentMode

| Campo | Tipo | Predefinito | Note |
|---|---|---|---|
| `enabled` | `boolean` | `false` | Attiva i comandi `gtag('consent', …)`. |
| `waitForUpdate` | `number` | `500` | Millisecondi che GTM aspetta un `update` prima di far partire i tag, solo quando non c'è ancora una scelta. |
| `adsDataRedaction` | `boolean` | `true` | Imposta `ads_data_redaction` quando `ad_storage` è negato. |
| `urlPassthrough` | `boolean` | `false` | Imposta `url_passthrough`. |
| `region` | `string[]` | tutte | Codici ISO 3166-2 a cui applicare i default (per esempio l'elenco SEE). |
| `dataLayerName` | `string` | `'dataLayer'` | Nome del data layer di GTM. |
| `eventName` | `string` | `'easy_cookie_update'` | Evento inviato al data layer alla prima scelta e a ogni modifica. |

Come usarli con Tag Manager: [Google Consent Mode v2 e GTM](/docs/consent-mode/).

## log

| Campo | Tipo | Predefinito | Note |
|---|---|---|---|
| `log.endpoint` | `string` | **obbligatorio** | Indirizzo del server dei consensi, per esempio `https://consent.example.com`. |
| `log.siteKey` | `string` | **obbligatorio** | Chiave pubblica del sito, `pk_…`. È di sola scrittura e si può mettere nell'HTML. |
| `log.requireLog` | `boolean` | `false` | Tiene il banner aperto, con un messaggio d'errore, finché il server non conferma il record. |

Senza `requireLog`, il cookie viene scritto subito e il record parte con `keepalive`. Se il server non risponde, il record resta in coda nel browser e viene ritentato alla visita successiva.

## ui

| Campo | Tipo | Predefinito | Note |
|---|---|---|---|
| `ui.position` | `'bottom-left' \| 'bottom-right' \| 'bottom' \| 'center'` | `'bottom-left'` | Posizione del banner. Sotto i 640px diventa un pannello a tutta larghezza in basso. |
| `ui.reopenButton` | `boolean \| { position?, hideOn? }` | `true` | Pulsante fisso che riapre le preferenze. `hideOn` accetta prefissi di percorso, per esempio `['/dashboard']`. |
| `ui.colorScheme` | `'light' \| 'dark' \| 'auto'` | `'light'` | `auto` segue `prefers-color-scheme`. |
| `ui.reloadOnWithdraw` | `boolean` | `true` | Ricarica la pagina quando una categoria già concessa viene revocata, perché gli script già eseguiti non si possono scaricare. |
| `ui.serviceToggles` | `boolean` | `true` | Interruttori per singolo servizio dentro ogni categoria. |

Se nascondi il pulsante con `hideOn`, offri comunque un link "Preferenze cookie" in quelle pagine (per esempio nel footer o nelle impostazioni dell'account), con `EasyCookie.openPreferences()`. Revocare deve restare facile quanto accettare.

## texts

Ogni testo visibile al visitatore si può sovrascrivere, per lingua. Basta indicare le chiavi che cambi:

```ts
texts: {
  it: {
    banner: { title: 'Cookie, solo se vuoi' },
    preferences: { save: 'Conferma' },
  },
  en: {
    banner: { title: 'Cookies, only if you want' },
  },
},
```

| Sezione | Chiavi |
|---|---|
| `banner` | `title`, `description`, `acceptAll`, `rejectAll`, `customize`, `close`, `policyLink`, `legendOn`, `legendOff` |
| `preferences` | `title`, `intro`, `acceptAll`, `rejectAll`, `save`, `close`, `alwaysOn`, `services`, `serviceCounter` (`'singolare\|plurale'`), `cookieName`, `cookieDuration`, `cookieDescription`, `provider`, `privacyPolicy`, `noCookies` |
| `reopen` | `label` |
| `embed` | `blocked` (con i segnaposto `{service}` e `{category}`), `enable`, `enableAlways` |
| `errors` | `logFailed` |

Non scrivere testi che spingono ad accettare ("Continua a navigare", "Accetta per un'esperienza migliore"): le linee guida chiedono un'informativa neutra.

## Esempio completo

```ts
import { defineConfig } from '@easy-cookie/core/shared';

export default defineConfig({
  revision: '2026-11-13',
  expiryDays: 182,
  policyUrl: { it: '/cookie-policy', en: '/en/cookie-policy' },
  language: { default: 'it', available: ['it', 'en'], autoDetect: 'document' },
  cookie: { name: 'ec_consent', sameSite: 'Lax', secure: true },
  googleConsentMode: { enabled: true, waitForUpdate: 500, adsDataRedaction: true },
  log: { endpoint: 'https://consent.example.com', siteKey: 'pk_live_xxx' },
  ui: { position: 'bottom-left', reopenButton: { hideOn: ['/dashboard'] }, colorScheme: 'auto' },
  categories: {
    necessary: { readOnly: true },
    experience: {},
    measurement: {},
    marketing: {},
  },
  services: {
    youtube: {
      category: 'experience',
      label: 'YouTube',
      provider: 'Google Ireland Ltd',
      privacyUrl: 'https://policies.google.com/privacy',
      cookies: [{ name: 'VISITOR_INFO1_LIVE', domain: '.youtube.com', duration: { it: '6 mesi', en: '6 months' } }],
    },
    ga4: {
      category: 'measurement',
      label: 'Google Analytics 4',
      provider: 'Google Ireland Ltd',
      privacyUrl: 'https://policies.google.com/privacy',
      cookies: [{ name: '^_ga', pattern: true, duration: { it: '2 anni', en: '2 years' } }],
    },
    meta: {
      category: 'marketing',
      label: 'Meta Pixel',
      provider: 'Meta Platforms Ireland Ltd',
      privacyUrl: 'https://www.facebook.com/privacy/policy',
      cookies: [{ name: '_fbp', duration: { it: '3 mesi', en: '3 months' } }],
    },
  },
});
```
