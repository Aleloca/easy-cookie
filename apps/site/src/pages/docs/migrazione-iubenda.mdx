easy-cookie copre la Cookie Solution (banner, preferenze, blocco preventivo, Consent Mode) e il Consent Database (prova del consenso). Non sostituisce il generatore di privacy policy, i termini e condizioni, IAB TCF né la geolocalizzazione: se ti servono, tienili.

## Finalità e categorie

Le cinque finalità di Iubenda hanno un id di categoria equivalente, con titolo, descrizione e segnali di Consent Mode già pronti:

| Finalità Iubenda | Id easy-cookie | Consent Mode |
|---|---|---|
| 1 · Strettamente necessari | `necessary` (con `readOnly: true`) | `security_storage` |
| 2 · Funzionalità | `functionality` | `functionality_storage` |
| 3 · Esperienza | `experience` | `personalization_storage` |
| 4 · Misurazione | `measurement` | `analytics_storage` |
| 5 · Marketing | `marketing` | `ad_storage`, `ad_user_data`, `ad_personalization` |

Dichiara solo le categorie che usi davvero: una categoria senza servizi è una domanda inutile per il visitatore.

```ts
categories: {
  necessary: { readOnly: true },
  experience: {},
  measurement: {},
  marketing: {},
},
```

## Il markup di blocco

Iubenda usa la classe `_iub_cs_activate` e l'attributo `data-iub-purposes` con il numero della finalità. In easy-cookie la categoria si indica per nome:

| Iubenda | easy-cookie |
|---|---|
| `class="_iub_cs_activate"` | non serve |
| `type="text/plain"` | `type="text/plain"` (uguale) |
| `data-iub-purposes="4"` | `data-category="measurement"` |
| `data-suppressedsrc="…"` (script) | `data-src="…"` |
| `data-suppressedsrc="…"` + `src="about:blank"` (iframe) | `data-src="…"`, senza `src` |
| `data-iub-type="module"` | `data-type="module"` |
| `_iub_cs_activate-inline` | non serve: gli script inline bloccati sono già supportati (non quelli che usano `document.write`) |

Prima:

```html
<script type="text/plain" class="_iub_cs_activate" data-iub-purposes="4"
        data-suppressedsrc="https://www.googletagmanager.com/gtag/js?id=G-XXXX"></script>
<iframe class="_iub_cs_activate" data-iub-purposes="3"
        data-suppressedsrc="https://www.youtube-nocookie.com/embed/ID" src="about:blank"></iframe>
```

Dopo:

```html
<script type="text/plain" data-category="measurement" data-service="ga4"
        data-src="https://www.googletagmanager.com/gtag/js?id=G-XXXX"></script>
<iframe data-category="experience" data-service="youtube"
        data-src="https://www.youtube-nocookie.com/embed/ID" width="560" height="315" title="Video"></iframe>
```

Gli iframe bloccati ora mostrano un segnaposto con le proporzioni giuste e un pulsante per attivarli, che Iubenda non offre in modo standard.

L'auto-blocco di Iubenda (lo script che blocca i domini noti) non ha un equivalente: ogni tag di terze parti va marcato. In compenso sai esattamente cosa viene bloccato.

## Opzioni equivalenti

| `_iub.csConfiguration` | easy-cookie |
|---|---|
| `perPurposeConsent: true` | Sempre attivo: il consenso è per categoria. |
| `purposes` | Le chiavi di `categories`. |
| `banner.acceptButtonDisplay`, `rejectButtonDisplay`, `customizeButtonDisplay` | Sempre presenti, con lo stesso peso. Non si possono nascondere. |
| `banner.closeButtonRejects: true` | Sempre così: la X vale come rifiuto. |
| `floatingPreferencesButtonDisplay` | `ui.reopenButton` (con `hideOn` per i percorsi esclusi). |
| `askConsentAtCookiePolicyUpdate`, `invalidateConsentBefore` | Cambia `revision`. |
| `preferenceCookie.expireAfter` | `expiryDays` (predefinito 182, cioè circa 6 mesi). |
| `invalidateConsentWithoutLog: true` | `log.requireLog: true`. |
| `googleConsentMode: 'template'` | `googleConsentMode: { enabled: true }`. |
| `googleAdsDataRedaction`, `googleUrlPassthrough` | `googleConsentMode.adsDataRedaction`, `urlPassthrough`. |
| `emitGtmEvents: true` | Sempre attivo: l'evento è `easy_cookie_update`. |
| `lang` | `language.default` e `language.available`. |
| `cookiePolicyUrl` | `policyUrl`. |
| `enableTcf`, `countryDetection` | Non supportati. |

## API JavaScript

| `_iub.cs.api` | `EasyCookie` |
|---|---|
| `showBanner()` | `showBanner()` |
| `openPreferences()` | `openPreferences()` |
| `acceptAll()`, `rejectAll()` | `acceptAll()`, `rejectAll()` |
| `setPreferences(…)` | `accept(['measurement'])` |
| `isConsentGiven()`, `getPreferences()` | `get()` |
| `getPurposesState()` | `isGranted('measurement')` per categoria |
| `resetStorage()` | `reset()` |
| `activateSnippets()` | Automatico alla scelta. |

| Callback Iubenda | Evento easy-cookie |
|---|---|
| `onReady` | `on('ready', …)` |
| `onConsentFirstGiven`, `onPreferenceFirstExpressed` | `on('consent', …)` |
| `onPreferenceChange` | `on('change', …)` |
| `onConsentGiven` | `onGranted('categoria', …)` |
| `onPreferenceExpressed` (a ogni caricamento) | `on('replay', …)` |

Vedi [API JavaScript](/docs/api/).

## Consent Database

| Iubenda | easy-cookie |
|---|---|
| Chiave pubblica, `POST /public/consent` | Chiave pubblica `pk_…`, `POST /v1/consents`, inviato dal runtime in automatico. |
| `ApiKey` privata | Chiave segreta `sk_…` in `Authorization: Bearer`. |
| `subject.id` | `identify(userId)` collega il consenso all'utente. |
| `legal_notices` con versione | Ogni record porta la `revision`; la configurazione di quella revisione è conservata. |
| `GET /consent`, `/subjects` | `GET /v1/consents`, `GET /v1/subjects/:id/consents`. |

Il registro di Iubenda resta da Iubenda: esporta i dati prima di disdire e conservali come prova dei consensi raccolti fino a quel momento.

## Cosa cambia per i visitatori

- **Ripeteranno la scelta una volta.** Il cookie di Iubenda (`_iub_cs-…`) non viene letto: a partire dal passaggio il consenso valido è quello in `ec_consent`.
- Il banner ha un aspetto diverso (i moduli colorati per categoria) e il pulsante per riaprire le preferenze mostra il loro stato.
- Accetta e Rifiuta sono sempre uguali, anche se nella configurazione Iubenda li avevi differenziati.

## Passaggi

1. Elenca i servizi attivi nel pannello Iubenda e riportali in `services`, con i cookie.
2. Converti il markup di blocco con la tabella sopra. Cerca `_iub_cs_activate` in tutto il codice e nei template.
3. Rimuovi `iubenda_cs.js`, `_iub.csConfiguration` e l'eventuale `safe.js`.
4. Metti lo snippet di easy-cookie in `<head>` prima di GTM, e in GTM sposta gli attivatori dagli eventi Iubenda a `easy_cookie_update` ([come](/docs/consent-mode/)).
5. Genera la tabella dei cookie con [@easy-cookie/policy](/docs/cookie-policy/) e aggiorna la cookie policy.
6. Verifica in una finestra anonima che prima della scelta non partano richieste verso terzi.
